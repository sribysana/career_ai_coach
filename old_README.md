This repository/project serves as the single source of truth for my interview preparation journey.

- Node.js
- Generative AI
- AI Agents
- MCP
- LangChain

This resulted in reduced momentum and delayed progress.

The key realization from this project is:

> Interview readiness is the primary goal.
>
> Learning unrelated technologies or chasing every trend should not interfere with that goal.

# Guiding Principles

## Focus Over Exploration

Avoid switching between unrelated topics.

Bad:

Node.js → AI → LangChain → System Design → AI Agents → Back to Node.js

Good:

Node.js → TypeScript → DSA → System Design → Interview Stories

---

## Build on Existing Strengths

Leverage existing experience in:

- React
- Enterprise Applications
- Leadership
- Production Support
- CI/CD
- Cloud Deployments

instead of attempting a complete career reset.

---

## Learn Through Real Systems

Whenever possible:

- Use actual project experience
- Use enterprise architecture examples
- Use production support examples
- Use deployment workflows

rather than toy examples.

# Core Rule

Whenever a new topic appears, ask:

> Will this significantly improve my chances of getting interviews within the next 60–90 days?

If the answer is no, place it in the backlog and continue executing the current plan.

Consistency is more valuable than constantly changing direction.
